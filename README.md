# Kunal Debnath — AI Engineer Portfolio

A modern, interactive personal portfolio website showcasing my work, technical skills, AI/ML projects, education, experience, certifications, and areas of interest.

The portfolio is designed with a dark, glassmorphism-inspired interface and interactive animations to create an engaging experience while keeping the focus on my work in Artificial Intelligence, Machine Learning, Deep Learning, LLMs, RAG, NLP, Computer Vision, and Speech AI.
